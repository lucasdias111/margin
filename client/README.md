# margin-desktop

Desktop and web client for [margin](https://margin.chat) — a collaboratory communications platform with text, voice, and
video chat.

[Download the app](https://margin.chat/download) or run it in your browser at [margin.chat](https://margin.chat).

## Got a question?

Check the [docs](../docs/) or open a [discussion](https://github.com/margin-chat/margin-desktop/discussions).

## Found a bug?

Please search [existing issues](https://github.com/margin-chat/margin-desktop/issues) before opening a new one.

## Contributing

Open a [discussion](https://github.com/margin-chat/margin-desktop/discussions) or send a pull request. There are plenty
of ways to help that don't require writing code.
